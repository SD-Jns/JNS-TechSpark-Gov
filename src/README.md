# AI Government Project Tracker

This folder contains a static front-end implementation inspired by the JNS AI Government Project Tracker dashboard.

## Files
- index.html — dashboard structure and layout
- styles.css — styling to match the reference design
- script.js — simple summary generator interaction

## View locally
Open the HTML file directly in a browser, or use any local static server.

Example:
- Open the file in VS Code with a browser preview extension, or
- run a simple local server from this folder with a tool available on your machine
